Connect the ESP32

  1. Wire the RC522 to the ESP32 and flash firmware/rfid_scanner/rfid_scanner.ino (see firmware/README.md).
  2. In the sketch, set your Wi-Fi name and password, and the key from step 1.
  3. Set the server address to your computer's address on the home network (not "localhost"):
const char* SERVER_URL = "http://YOUR-COMPUTER-IP:5000/api/iot/scan";

Find your computer's address with ipconfig. Start the site with set HOST=0.0.0.0 first so the ESP32 can reach it.
